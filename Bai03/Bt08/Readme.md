# BÀI TẬP 08 – THAO TÁC TẬP TIN VÀ THƯ MỤC

## 1. Thông tin sinh viên

- Họ và tên: Nguyễn Lê Duy Anh
- Mã sinh viên: CD-CNTT18A03
- Lớp: CD-CNTT18A

## 2. Mục tiêu bài tập

Sử dụng module File System (fs) trong Node.js để thực hiện các thao tác quản lý thư mục và tập tin.

## 3. Nội dung thực hiện

- Sử dụng module fs tạo thư mục data.
- Tạo tập tin ghichu.txt và ghi 3 dòng nội dung.
- Đổi tên tập tin thành ghichu_moi.txt bằng fs.rename().
- Đọc và hiển thị nội dung sau khi đổi tên.
- Tạo tập tin tam.txt.
- Xóa tập tin tam.txt bằng fs.unlink().
- Hiển thị thông báo kết quả từng thao tác.

## 4. Lệnh chạy chương trình

```bash
node bai08.js
```
